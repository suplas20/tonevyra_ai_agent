# Expert Reference Evaluation Skill

## Purpose

Use this skill for T-026 expert reference linkage, blind pair creation, randomized human review, reviewer confidence, and evidence-backed quality claims.

## Core Rule

Do not claim “expert 100” or a numeric quality target without a documented reference set, scoring rubric, reviewers, and run evidence.

## Reference Requirements

Each reference needs source linkage, expert/editor scope, Lightroom/settings provenance when available, license/consent, and checksum.

## Blind Review

- randomize A/B order;
- hide provider/version labels;
- avoid showing model reasoning before scoring;
- record criteria scores, preference, confidence, and notes;
- retain reviewer and session identifiers without exposing unnecessary personal data.

## Scoring

Keep expert/human scores separate from automated technical metrics. Combine only through a documented versioned aggregation formula.

## Acceptance Checklist

- blind/randomized evidence exists;
- reference provenance is traceable;
- human and automated scores remain separable;
- reviewer confidence and disagreement are retained;
- unsupported numeric quality claims fail validation.
