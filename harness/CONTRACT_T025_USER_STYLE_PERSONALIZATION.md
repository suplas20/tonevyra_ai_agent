# T-025 User Style Profile and Personalization Harness Contract

## Contract

- Profiles are local, user-scoped, explicit, versioned, rollbackable, and opt-out capable.
- Style preferences are high-level Planner inputs, not executable Lightroom commands.
- Technical safety overrides style.
- Feedback calibration needs minimum evidence and bounded changes.
- Automatic model fine-tuning, external transfer, and cross-user mixing are forbidden.
- Strict evidence includes create/activate/apply/rollback/opt-out flows.
- T-019 through T-024 regressions remain mandatory.
